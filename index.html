About

Chessgui organises a personal library of chess games — importing them, searching them, grouping them into collections and tags, and opening any one of them for analysis. It is built around a tabbed workspace: a Library for finding games, a Game workspace for studying one, and Settings for everything else.

The network may add information; it must never be required for the application to function.

That rule shapes the whole design. Games can synchronise from online sources such as Chess.com and Lichess, but those are enrichment, never a dependency: with no connection, previously fetched games stay browsable and every other feature works unchanged — only synchronising is unavailable. Fonts, icons, themes and translations are all bundled, so nothing is fetched at runtime.

This is a prototype of the interface, not a working chess application. It runs on sample data: the games, collections and subscriptions you see are fixtures. Nothing is saved, and no real database is opened.

Install for offline use

Chessgui is a Progressive Web App, so it installs from the browser — no download, no app store. Once installed it opens in its own window and runs with no connection at all.

Chrome or Edge, desktop

Launch the app, then click the install icon at the right-hand end of the address bar — or open the browser menu and choose Install Chessgui.

Safari, macOS

Launch the app, then choose File → Add to Dock. Requires macOS Sonoma or later.

iPhone and iPad

Launch the app in Safari, tap the Share button, then Add to Home Screen.

Android

Launch the app in Chrome, open the browser menu, then Install app or Add to Home screen.

The first visit needs a connection. Installing stores the whole application — around 700 KB including fonts and icons — on your device. After that it opens offline, and updates itself whenever you next open it online.

Before you start

  • It is designed for a desktop-sized window. The layout assumes at least 800 × 600, and says so rather than reflowing below that.
  • Light and dark both work, and follow your system setting unless you choose one in the app.
  • It speaks English, German and French, switchable from the application menu.
